# Locked plan — 2026-11-11
## Product
Tomorrow's Design System is a local open-source, single-user visual system design simulator for engineering choices, performance, reliability, resilience and monthly cost comparison. All infrastructure experiments are simulated. Build architecture, configure workloads, generate/edit scenarios, run, inspect animated traffic, compare alternatives. Broad initial catalog: clients, networking, edge, routing, security, compute, applications, database topologies, caching, storage, messaging, workers, data systems, AI, dependencies, observability, recovery and deployment boundaries.
Time is simulated independently from playback. Events: timestamp, sampled interval, metric condition; failure/recovery, traffic, latency, capacity/scaling. Workflows support branching, cache miss, async queues. Cloud: AWS/GCP/Azure, AI: OpenAI/Anthropic/Google/OpenRouter. Live pricing/published limits where available; provenance, cached snapshots, manual/account overrides, honest missing values. Cost per experiment and monthly assumptions. Models versioned; seeded reproducibility, reference tests, uncertainty, measurement calibration. Do not confuse broad catalog with calibrated fidelity.
## Factory

Specialists: research/skills, architecture, simulation, cloud/cost, UX/design, frontend, backend, QA, release, agent reliability/human factors. Skills versioned in repository; approved templates only. Tasks have IDs, dependencies, acceptance, scope, context versions, leases, heartbeats, attempts, timeouts, bounded retries, evidence. Persistent state machine; independent review; trusted checks; worktree isolation; sequential integration; restart recovery; resource budgets; pause/cancel/resume; dashboard; failures injected in tests. Reviewer checks context overload, unsupported assumptions, contradictions, user comprehension, misleading precision and actual artifacts. No self-approval. Tests cannot be weakened to pass. No native Codex subagents. This chat supervises bootstrapping; durable local factory owns ongoing state.
