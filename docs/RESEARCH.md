## Modeling and calibration proposal

Use stdlib heapq with stable event sequence IDs, a per-run seeded random generator and independent presentation sampling. Exact event tie/horizon semantics must be declared and tested against the implementation. Track request and background-job populations separately. Finite-run unfinished requests are pending, not silently successful or discarded. Broad component labels need their actual generic model and limitations exposed.

Start with independent hand calculations: idle system, deterministic single server, finite queue saturation, fail/recover interval, routing branch and one-hour cost. A queueing formula is an oracle only when its assumptions match. These are verification checks. For calibration, capture measured arrivals/service times/errors and environment configuration; pin trace/model versions, fit only a training portion, evaluate on held-out workloads, and report declared error metrics plus uncertainty and applicability range. Compare multiple seeds and parameter sensitivity; sampling variation does not quantify structural bias. No calibration dataset, calibrated parameter fit or accuracy result was available in this research assignment.

## Pricing and worker tooling proposal

Use stdlib urllib/decimal/json for bounded HTTP refresh and unit-aware price arithmetic where suitable. Retain raw snapshot identity/hash, fetch time, source URL, effective time, currency, SKU/model, region, unit and term; normalize into a quote only after validation. Preserve last good data on refresh failure. Show missing values explicitly. Monthly 730 hours and traffic multiplier are assumptions, with storage/egress/taxes/discount exclusions stated. Published limits require their own source; pricing evidence does not establish throughput or latency.

Use stdlib subprocess behind a provider adapter, durable local task state (SQLite transactions or demonstrably safe journal), isolated worktrees and sequential coordinator integration. Persist task/dependency/context versions, attempts, leases, deadlines, heartbeats, budgets and evidence paths. Resume by explicit session/task identity. On restart fence stale completions and reconcile orphan workers before retrying. Inject termination, malformed output, duplicate result, lease expiry and interrupted integration. Do not promise exactly-once execution; make repeated result handling idempotent. CLI flags and provider access remain installation-dependent until tested locally.
